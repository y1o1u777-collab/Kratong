# Krathong Live · คืนลอยกระทง 3D

เว็บไซต์ลอยกระทงออนไลน์ฉบับอัปเกรด สำหรับ **โรงเรียนเตรียมอุดมศึกษาพัฒนาการ ปทุมธานี**
กระทงทุกใบในเว็บเป็น **โมเดล 3D จริง** — ตั้งแต่หน้าหลัก คลังกระทง หน้าสร้างกระทง หน้ารายละเอียดคำอธิษฐาน ไปจนถึงฉากจับคู่และพิธีลอยกระทง

## สิ่งที่อัปเกรดในเวอร์ชันนี้

- **กระทง 3D ทุกจุดในเว็บ** (ไม่มีรูปกระทง 2D เหลืออยู่)
  - หน้าหลัก: กระทงลอยอยู่บนแม่น้ำพร้อมแสงเทียน
  - คลังกระทง: ทุกคำอธิษฐานกลายเป็นกระทง 3D ที่กดเปิดอ่านได้ (รองรับคีย์บอร์ด)
  - หน้าสร้างกระทง: พรีวิวกระทง 3D แบบสด สลับแบบทอง/บัวชมพูได้ทันที
  - หน้ารายละเอียด: แสดงกระทง 3D ของคำอธิษฐานนั้น
  - การ์ดจับคู่: กระทงคู่ 3D ที่ขยับเข้าหากันตามสถานะการจับคู่
- **โมเดลกระทงละเอียดขึ้น** — ใบตองพับหนาแบบ 3D, กลีบบัวไล่เฉดสีหลายชั้น, ขอบทอง, เทียนที่มีหยดขี้ผึ้ง, ธูปพร้อมควัน, ดอกดาวเรือง
- **แสงสีอลังการ** — ไฟเทียนแบบ point light, แสงอุ่นด้านหน้า, ชั้น glow แบบ additive, ประกายไฟ, หิ่งห้อย, แสงจันทร์พร้อม flare, ผิวน้ำ shader ที่สะท้อนแสงเทียนและแสงจันทร์
- **GSAP** จัดลำดับ: เทียนติดทีละเล่ม → ธูป → ประกายไฟ → กระทงลอยออกไป พร้อมข้อความคำอธิษฐานลอยขึ้นเป็นแสง
- **ระบบเดิมครบ** — สร้างกระทง, บันทึกในเครื่อง, คลังกระทง, จับคู่ + แชท, SQLite/Supabase
- **ไม่ต้องติดตั้งไลบรารีเพิ่ม** — Three.js (r170) และ GSAP 3.12.5 + ScrollTrigger อยู่ใน `public/vendor`

## เปิดใช้งาน

ต้องมี **Node.js 22.13 ขึ้นไป** เปิดเทอร์มินัลในโฟลเดอร์ที่มี `package.json` แล้วรัน

```sh
npm start
```

เข้า [http://localhost:3000](http://localhost:3000) โหมดนี้ใช้ SQLite ซึ่งจะสร้าง `data/wishes.sqlite` เมื่อเริ่มรันครั้งแรก

ทดลองจับคู่ด้วยสองหน้าต่าง หรือเปิดจากอีกเครื่องใน Wi-Fi เดียวกันผ่าน `http://<IP-เครื่องเซิร์ฟเวอร์>:3000`
ทั้งสองฝ่ายกรอกชื่อเล่น เลือกเพศหรือไม่ระบุ เลือกความชอบ แล้วกด **เริ่มหาเพื่อน**
เพิ่ม Instagram และรูปได้ตามต้องการ รูปรองรับ JPG, PNG, WebP และ AVIF สูงสุด 8 MB และจะถูกครอปและย่อในเบราว์เซอร์ก่อนส่ง

ระบบจะเลือกคู่ที่มีความชอบตรงกันมากที่สุดจากคิว ถ้าคะแนนเท่ากันจะสุ่ม หากยังไม่มีคนที่ชอบตรงกัน ระบบให้เวลา 8 วินาทีก่อนสุ่มจากคิว
เมื่อจับคู่แล้วแชทได้ทันที และกระทง 3D ทั้งสองใบจะลอยเข้าหากันเมื่อทั้งคู่กด **พร้อมลอยกระทง**

## การเล่นกับฉาก 3D

- เลื่อนเมาส์บนหน้าหลัก/คลังกระทงเพื่อขยับมุมมองเล็กน้อย
- คลิก/แตะผิวน้ำเพื่อสร้างระลอก (หรือกดปุ่ม `≋`)
- กด **สร้างกระทงของฉัน** → พรีวิว 3D จะเปลี่ยนตามแบบที่เลือก → เขียนคำอธิษฐาน → **จุดแสงและปล่อยกระทง**
- เทียนจะติดทีละเล่มพร้อมประกายไฟและระลอกน้ำ ธูปเริ่มมีควัน แล้วกระทงลอยออกไปพร้อมคำอธิษฐานลอยขึ้นเป็นแสง
- ในคลังกระทง กดกระทง 3D ใบใดก็ได้เพื่ออ่านคำอธิษฐาน (หรือ Tab ไปที่กระทงแล้วกด Enter)
- การ์ดจับคู่จะเปลี่ยนฉาก 3D ตามสถานะ: รอคู่ / จับคู่แล้ว / พร้อมลอย / ปล่อยแล้ว

หากเบราว์เซอร์ไม่รองรับ WebGL ระบบจะแสดงฉากและกระทงแบบ CSS สำรองให้อัตโนมัติ
ผู้ที่ตั้งค่า **ลดการเคลื่อนไหว** จะได้ฉากนิ่งและเทียนที่ติดไฟแบบไม่ขยับ

> หมายเหตุ: ฉาก 3D โหลดผ่าน ES Module จึงต้องเปิดผ่าน HTTP (`npm start`) — หากเปิด `public/index.html` จากไฟล์ตรง ๆ เบราว์เซอร์จะบล็อกโมดูลและเว็บจะใช้ฉาก CSS สำรอง

## เปิดใช้ Supabase

1. เปิด **SQL Editor** ในโปรเจกต์ Supabase แล้วรัน `supabase.sql`
2. ทำสำเนา `.env.example` เป็น `.env` ใส่ **Project URL** ใน `SUPABASE_URL` และ **Secret key** ใน `SUPABASE_KEY` (เก็บคีย์ไว้ฝั่งเซิร์ฟเวอร์เท่านั้น)
3. รัน `npm run start:supabase` หรือกำหนดตัวแปรเดียวกันที่โฮสต์แล้วใช้ `npm start`
4. เปิดฟอร์มสร้างกระทงและเลือก **เผยแพร่ชื่อที่แสดงและคำอธิษฐานบนแม่น้ำสาธารณะ**

เมื่อเปิด Supabase กระทงสาธารณะจะถูกบันทึกลง Supabase ส่วนคิวจับคู่ โปรไฟล์ รูป และแชททำงานในหน่วยความจำของ Node.js
ข้อมูลห้องแชทถูกล้างเมื่อจบการจับคู่ และเมื่อรีสตาร์ตเซิร์ฟเวอร์ทุกคนต้องเข้าคิวใหม่
การแชร์กระทงจะอัปเดตหน้าริมสายน้ำผ่าน SSE เดียวกับแชท

## การโฮสต์

โฮสต์ด้วยเว็บเซอร์วิสที่รัน Node.js ต่อเนื่องและรองรับ HTTP streaming (SSE) ใช้ `npm start` และพอร์ตจาก `PORT`
ใช้เซิร์ฟเวอร์ **หนึ่งอินสแตนซ์** เพื่อให้ทุกคนอยู่คิวเดียวกัน หากมี reverse proxy ให้ส่งสตรีม `/api/events` โดยไม่บัฟเฟอร์
ตั้ง `TRUST_PROXY=1` เฉพาะเมื่อใช้ proxy ที่อยู่หน้าตัวเซิร์ฟเวอร์โดยตรง

## โครงสร้างไฟล์สำคัญ

- `public/krathong3d.js` — เอนจิน 3D ทั้งหมด: โมเดลกระทง, shader น้ำ, แสง, ฉาก hero/launch/gallery/pair/viewer
- `public/app.js` — ฟอร์ม, คลังกระทง, การเชื่อมต่อฉาก 3D, modal, toast
- `public/match.js` — จับคู่/แชทผ่าน SSE
- `public/motion.js` — GSAP hero intro + reveal + parallax
- `public/vendor/` — three.module.js, gsap.min.js, ScrollTrigger.min.js
- `server.js`, `wishes.js` — HTTP server, SSE, SQLite/Supabase
